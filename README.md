# Robert Liu: Personal Website

A clean, single-page personal site hosted on GitHub Pages. No build tools, no frameworks: just one `index.html` file you edit directly.

## Live site

Once GitHub Pages is enabled, your site is live at:

**https://YOUR-USERNAME.github.io**

## How to edit

Everything is in `index.html`. Open it and look for the `EDIT:` comments that mark exactly what to change.

- **Tagline**: the one-liner under your name in the hero section.
- **Experience**: copy a `<div class="entry">` block for each job.
- **Projects**: copy an `<article class="project">` block for each project. Fill in the title, description, tech tags, and links (live demo / code).
- **GitHub link**: in the Contact section, replace `https://github.com/` with your profile URL.

## Re-theming

Change the site's accent color in one place: the `--accent` value near the top of the `<style>` block. Dark mode is automatic based on the visitor's system setting.

## Updating after it's live

Edit `index.html` on GitHub (pencil icon) or push changes from your computer. GitHub Pages redeploys automatically within a minute or two.
