Interconnect Board (UI v1.4)

The interconnect board that ties the Raspberry Pi to every signal around the robot.

Role: Board design — v1.4 revision
Team: UBC Thunderbots (RoboCup autonomous soccer robots)

Code ↗ Team ↗

Overview

UBC Thunderbots builds fully autonomous soccer-playing robots for the RoboCup Small Size League. The interconnect board is the hub that routes signals between the robot's Raspberry Pi compute module and the subsystems around it — motors, sensors, and control electronics — so the high-level software can reach every part of the robot.

I worked on the v1.4 revision of this board.

What I did

  • Contributed to the v1.4 design of the interconnect board, routing the connections between the Raspberry Pi and the robot's signal lines.
